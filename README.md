# Bunny's Magical Diwali 🐰🪔

Single-file static site (index.html). Three.js loads from cdnjs, so internet is needed.

## Run locally
Open `index.html` in Chrome. (Mic features need https, so test those on the deployed site.)

## Deploy on Vercel
1. Put this folder in a GitHub repo, then import it at vercel.com/new (no build settings needed), or
2. Run `npx vercel` inside this folder and follow the prompts.
